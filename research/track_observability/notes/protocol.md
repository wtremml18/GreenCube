# Experiment protocol — frozen before outcome inspection, 2026-10-18

Question: Does low validation error on dense parallel tracks certify reconstruction between tracks when the interpolator is exactly divergence free?

Primary evidence: (1) an explicit smooth divergence-free field invisible on complete parallel tracks, (2) a finite Fourier-basis nullspace diagnostic with an explicit coefficient budget, (3) independent synthetic field/noise realizations comparing random-point and leave-track-out tuning, and (4) exploratory held-out-location prediction on two public ocean-current subsets. The diagnostic is a conditional sensitivity calculation, not a confidence interval or a new general inverse-problem theorem.

Synthetic design: unit square; four horizontal tracks at y = .125, .375, .625, .875; x spans .025 to .975; 12, 24, 48 observations per track. Forty seeds (0–39), random Fourier streamfunctions with integer wavevectors up to 3 and coefficient decay (1+|k|²)^(-1.5); component noise SD .05. Evaluate a fixed independent 31×25 grid inside the track envelope. Compare normalized Gaussian solenoidal and independent-component kernels; tune length [.08,.16,.32,.64] and ridge [1e-4,.01,.1] using four folds. Random folds and leave-track-out folds evaluate different prediction tasks. Report error against clean truth and error against noisy validation data separately; never interpret selected CV loss as an unbiased generalization estimate. Fit mean from training data only. Use paired seed-level bootstrap intervals, not grid-point confidence intervals.

Blind-field experiment: streamfunction sin(2πx) sin²(4π(y−1/8)); its rotated gradient vanishes on all four full tracks. Normalize its vector RMS on the evaluation grid. Hold training data and reconstruction fixed while adding amplitudes 0, .25, .5, 1, 2. This is a deliberate counterexample, not a representative field distribution.

Observability: real Fourier streamfunction basis through integer frequency 4, coefficient weights (1+|k|²)^(-1.5). Compute nullspace of the observation matrix by SVD, and largest target RMS singular value within that nullspace. Compare more along-track points with additional off-track points. Investigate frequency 3, 4, 5 and jitter sensitivity; conclusions are basis- and tolerance-dependent.

Public data: use fixed, checksum-recorded GLAD and LASER subsets from Helmholtz-GP. Treat them as preprocessed velocity observations, not simultaneous ground truth or ionospheric measurements. Nested spatial quadrant holdout with solenoidal, independent, and mixed Helmholtz kernels tests sensitivity to the hard constraint. Full preprocessing and exact split indices must be saved. No claims about physical divergence can be inferred solely from held-out velocities.

Selection: report every specified condition, including unfavorable outcomes. Any changes after seeing results must be recorded here. No journal submission or authorship approval is implied by a generated draft.

Implementation clarification (before primary synthetic results): public subsets are capped at 160 observations each using RNG seed 20261018; spatial holdout uses median quadrants, with inner median quadrants recomputed on each outer training set. Coordinates are centered and scaled isotropically using outer-training geometry to preserve the divergence constraint. The underlying public CSV files lack time and buoy identity, so this is location holdout, not buoy- or time-independent validation.

Analytical extension (added during implementation, not a preregistered claim): exact numerical nullity can disappear under arbitrarily small coordinate jitter. Therefore also report a noise-budget sensitivity radius from max ||B c||/sqrt(m) subject to ||c||² + ||A c||²/(n delta²) <= 1, for delta=.001,.01,.05. This is an exact radius for the combined ellipsoid and a LOWER bound on the radius for separate coefficient and noise budgets. It uses a generalized eigenvalue calculation; it is not a statistical coverage bound. Independent noise averaging is not modeled by this deterministic sensitivity calculation.

Secondary experiment added after inspecting the primary results: the primary study showed track-density saturation, and the exact-null audit suggested additional off-track locations could reduce ambiguity. Run a paired intervention with 8 or 32 new measurements either on the existing four lines or at uniformly random locations inside their envelope. Reuse each seed's original 96 noisy observations, field realization, and added-noise draws across the two designs. Tune the DF kernel with random four-fold CV. This is an exploratory follow-up, not a confirmatory predeclared outcome; it tests 40 seeds from the same Fourier distribution and requires broader validation.

Exploratory geometry/weighted-flux extension (added after track and public-fluid results): test an explicit invertible arc map X(s,n)=(s,n+0.12 sin(2pi s)) and known vertical magnetic field magnitude B=exp(0.8x). Push forward the earlier random Fourier reference fields using the Piola map and divide by B. Twenty seeds; 96 observations on four vertical crossings in reference coordinates and the previous 775-point target grid; noise SD .05. Compare correct geometry, amplitude .08, straight geometry, reversed curvature, and a naive straight divergence-free velocity model ignoring variable B. Fit a jointly estimated constant reference-flux background by generalized least squares. All methods share observations and random four-fold tuning. This is an oracle geometry stress test, not extraction of geometry from images or validation on aurorae. Test both ordinary and B-weighted numerical divergence and covariance PSD. No image accuracy or calibrated uncertainty claim follows.
